# Proposal Website

Open `index.html` in a browser to view the interactive proposal page. Replace the photo URL in `index.html` and customize text to personalize.

Files added:
- `index.html` — main page
- `styles.css` — styling and animations
- `script.js` — interaction, confetti and sound

To test locally (Windows):

1. Open File Explorer to this folder.
2. Double-click `index.html` to open in your default browser.

For best effect use a modern browser (Chrome, Edge, Firefox).
